Two separate scans of the same n items do n + n = 2n visits, so their total remains O(n). An outer n loop with an inner loop of exactly three steps performs 3n body visits, also O(n). Count the actual bounds rather than the number of for keywords.

If every one of n items is paired with every one of another m items, the pair body runs n × m times: O(nm). If both inputs have length n, this becomes O(n²). For n=10, all ordered pairs give 100 bodies; for n=20, 400. Doubling both dimensions gives four times the work.

Pairing only distinct positions with j > i gives n(n−1)/2 visits. It avoids duplicates but still grows quadratically. Sequential n² work followed by n work has total n² + n, whose dominant growth is O(n²). These claims assume a constant-cost body; inspect calls inside it too. 

for item in items:       # n visits
    visit(item)
for item in items:       # another n visits
    visit(item)

for left in items:
    for right in items: # n visits for each outer item
        compare(left, right)
