Trace the input, decision, and result. This diagram simplifies the mechanism; your local code tests its stated contract.

Ruff checks many lint rules and formats Python; a type checker such as mypy or Pyright checks annotated relationships. Neither proves that business rules or permissions are correct. Run focused behaviour tests as well.

eval executes Python expressions, and pickle can execute code while loading. They are inappropriate parsers for untrusted API/config data. Use a data parser and validate its result. Dependencies also execute code: use trusted packages, isolated environments, reviewed versions, and avoid importing installation commands into application logic.
