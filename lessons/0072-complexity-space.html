02 / EXPLORE

One mechanism to use today.

Retained inputstate supplied by caller
→
Auxiliary stateworking data and stack
→
Output storagereturned or consumer-retained values

Time complexity describes growing work. Space complexity describes growing storage. State the convention: auxiliary space excludes input and output; total additional storage includes newly allocated output. A loop index and running total use constant auxiliary state in this small-number model.

A list of n transformed values takes O(n) output storage. A lazy generator producing one value at a time can use O(1) auxiliary state while iterating, excluding upstream state. If its consumer calls list(generator), the retained output still takes O(n) space.

A generator with a seen set of every unique ID is not constant-space processing: that set grows. Recursion also retains stack frames. Count what remains live at the same time, not all objects ever allocated. Big-O counts here are conceptual slots, not measured allocation bytes or process RSS. 

# Both can produce n doubled values.
eager = [2 * value for value in items]  # retains n results
lazy = (2 * value for value in items)   # produces on request
stored_again = list(lazy)              # now retains n results
