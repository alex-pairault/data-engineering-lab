Validation and serialization solve different problems. A valid internal record may contain fields that a public response must omit. Define a public schema and construct it from explicitly selected values; do not dump an internal object indiscriminately.

Pydantic v2 uses model_validate, model_dump and model_dump_json; v1 examples often use parse_obj, dict and json. Migration involves changed validation semantics too. Python-mode and JSON-mode validation can differ, particularly for strict date/time inputs.
