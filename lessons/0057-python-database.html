SQLAlchemy offers a SQL toolkit and an ORM. This lesson uses Core text statements so the database behaviour stays visible. engine.begin() creates a transaction context: commit on normal exit, rollback if an exception escapes.

Parameters bind values separately from SQL syntax. They do not replace table or column identifiers. The fixture uses SQLite with modern transaction control on Python 3.12+; different databases have different concurrency/isolation behaviour. This is a single-writer contract exercise, not a distributed transfer system.
