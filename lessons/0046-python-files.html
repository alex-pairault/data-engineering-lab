Trace the input, decision, and result. This diagram simplifies the mechanism; your local code tests its stated contract.

A context manager handles entry and cleanup. with open(..., encoding="utf-8") closes the handle when the block exits, including after an exception. Specify an encoding rather than depending on the platform or Python version.

JSON Lines stores one JSON value per line. This exercise accepts object rows and skips blank lines; malformed JSON or a non-object value fails explicitly. CSV needs csv, including newline="" for files; splitting on commas mishandles quoted fields. Never unpickle untrusted data.

A generator suspended inside with open still owns the open file. Full consumption, an escaping error, or explicit generator.close() exits that block. If stopping early, use with contextlib.closing(read_jsonl(path)) as rows: and consume inside it; an early break alone does not close a retained generator.
