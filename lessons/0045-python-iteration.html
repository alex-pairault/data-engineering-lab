Trace the input, decision, and result. This diagram simplifies the mechanism; your local code tests its stated contract.

An iterable supplies an iterator; an iterator advances with next and raises StopIteration at the end. A generator function uses yield and suspends between requests. It is usually single-pass, not a reusable stored collection.

Lazy filtering avoids retaining all accepted rows. It does not make every operation bounded: list(generator), sorting all rows, or retaining every unique key can still grow with input. The consumer controls how far the producer advances.
