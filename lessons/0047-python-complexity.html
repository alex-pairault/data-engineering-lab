Trace the input, decision, and result. This diagram simplifies the mechanism; your local code tests its stated contract.

A repeated x in list scan can make a deduplication loop quadratic as input grows. A set normally gives average constant-time membership; an output list can separately preserve first-seen order.

This trades CPU work for retained state: seen and output grow with distinct IDs. A generator wrapped around an unbounded seen set is not constant-memory deduplication. Bound the data or use external state when the domain requires it.
