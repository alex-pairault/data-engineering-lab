As checked on November 5, 2026, Python 3.15 is stable; 3.10 is end-of-life. The exercises deliberately use a Python 3.12 baseline and record the exact tested environment. Check the developer status table when you revisit this lesson rather than treating this snapshot as permanent.

Recognize useful milestones: 3.10 match/case and X | Y unions; 3.11 ExceptionGroup, TaskGroup, tomllib; 3.12 type-parameter syntax and type aliases; 3.13 experimental free-threaded CPython; 3.14 deferred annotations and supported optional free-threaded builds; 3.15 UTF-8 mode by default and explicit lazy imports. Each upgrade also changes removals, APIs, wheels, and tooling.

A runtime if cannot protect newer syntax elsewhere in the same module from an older parser. Keep new syntax in a separate file or compile a small string in a feature probe. Do not assume a version number enables an optional GIL-free build or JIT.
