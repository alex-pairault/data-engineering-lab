Processes can execute CPU work in separate interpreters, at the cost of startup, serialization, and separate memory. In this exercise spawn starts fresh processes; the worker function must be defined at module level and importable.

The tiny fixture is intentionally too small to promise speedup. A larger CPU workload needs benchmarks and a memory budget. Use a main guard for standalone CLI process creation; do not trigger a pool at import time. Shared database clients and arbitrary closures are poor process arguments.
