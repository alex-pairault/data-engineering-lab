Trace the input, decision, and result. This diagram simplifies the mechanism; your local code tests its stated contract.

Pydantic v2 validates data into declared models. By default, some values are coerced. ConfigDict(strict=True, extra="forbid") makes this exercise reject string integers, bools for ints, and unknown fields. Field constraints express positive IDs and nonnegative cents.

Validation is a boundary, not authentication or authorization. model_validate checks a Python object; model_construct bypasses validation and is inappropriate for untrusted input. A successful schema also does not prove the order exists or belongs to this user.
