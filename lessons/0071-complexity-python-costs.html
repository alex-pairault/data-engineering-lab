02 / EXPLORE

One mechanism to use today.

End-to-end workinclude the hidden operation

Python syntax length does not measure work. For an ordinary CPython list, len(items) and indexing one known element are O(1). A missing-value membership test scans n items in the worst case: O(n). A slice that copies k elements needs O(k) work and O(k) result storage.

Appending to a list is amortized O(1): averaged across a sequence of appends, resizing is spread over many operations. A particular resizing append can cost O(n). Removing the first item with pop(0) shifts the remaining references and costs O(n); deque.popleft is the appropriate queue operation when its contract fits.

Dict/set lookup is expected or average O(1) under normal hashing assumptions; collisions can cause a worse case. Keys still need hashing and equality: large strings, arbitrary-size numbers, or expensive custom methods can change costs. This course uses small fixed-size keys. 

wanted in items       # may scan the list
items[:k]             # copies k references
items.append(value)   # amortized constant, not every call
seen.add(value)       # expected constant with suitable keys
