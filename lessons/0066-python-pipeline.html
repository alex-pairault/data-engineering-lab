Combine earlier skills in a bounded batch. This contract treats identical repeats of an order ID as a replay to ignore, but rejects conflicting records for an existing ID. Choosing first-wins or latest-wins silently would be a different business policy.

Validate all rows before filtering paid status; an invalid pending row should not disappear unnoticed. The exercise keeps a dict of unique orders, so its memory grows with distinct IDs. It is a batch calculation without external writes, not proof of durable exactly-once ingestion.
