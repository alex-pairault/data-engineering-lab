Threads share a process and its memory. In ordinary GIL-enabled CPython, one thread at a time executes Python bytecode, while many blocking I/O operations release the GIL. Native libraries can release it too. Optional free-threaded builds differ; neither model makes arbitrary compound business logic safe.

Use a bounded executor for blocking I/O-shaped calls, avoid shared mutable accumulators, and collect results so worker exceptions surface. This exercise uses deterministic injected work; it does not claim a measured network speedup. More workers can multiply in-flight buffers and remote load.
