Trace the input, decision, and result. This diagram simplifies the mechanism; your local code tests its stated contract.

Elapsed time measures wall-clock duration; process CPU time measures CPU consumed by this process. I/O waits can increase elapsed time without similar CPU use. RAM holds live objects and buffers; CPU cores execute work. More workers can increase concurrent working memory.

CPython uses reference counting plus cyclic garbage collection. Allocator arenas and native-library memory mean freed Python objects need not reduce resident process memory. tracemalloc observes traced Python allocations, not total RSS. sys.getsizeof is a shallow object size, not its complete reachable graph.

The supplied memory_probe.py runs eager and streamed versions in fresh processes at 10,000 and 100,000 items. Timing and allocation tracing use separate runs; output must match. The probe measures two prepared implementations, independently of your total_squares function; adapt it to your own code as a later extension. Do not impose machine-specific speed thresholds.
