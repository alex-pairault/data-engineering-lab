pandas offers labelled columns, grouping, and joins. Filter paid orders before aggregation, then merge one row per customer back onto the complete customer list. validate="one_to_one" checks the expected merge relationship.

A DataFrame is normally materialized in memory; vectorized operations can also allocate intermediates. NumPy supplies array operations underneath much of this ecosystem. Polars offers a lazy query API, but neither lazy execution nor a streaming engine guarantees every query has bounded memory. Choose from data shape and measurements.

Keep input amounts and each grouped total within the signed 64-bit integer range for this fixture. Use pandas nullable Int64 before a merge that introduces missing totals, so the intermediate does not round large integers through float64.
