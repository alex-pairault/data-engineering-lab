Useful failure evidence locates an operation, release, stage and outcome. A request ID can correlate records across a proxy and application. A nearby successful message may belong to a completely different request.

Follow r-18 in the synthetic stream. The proxy’s 502 and upstream connection refusal share its identity and release. That supports checking the intended upstream listener and configuration. Correlation helps narrow the investigation; it is not proof that every similarly timed record caused the failure.

Sentry can capture error events and context. An event is an occurrence; an issue groups related events. Reporting an exception does not repair an operation, and a caught exception may need deliberate capture. Logs, metrics, traces and error reports answer related but different questions.

Keep credentials, session tokens and raw sensitive payloads out of context. The download serializes an explicit narrow field schema and checks that a planted synthetic token is absent. Review values as well as field names. Default SDK scrubbing is not proof that arbitrary context is safe. This lesson sends no outbound Sentry event and requires no account.
