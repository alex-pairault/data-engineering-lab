Trace the input, decision, and result. This diagram simplifies the mechanism; your local code tests its stated contract.

A function groups a contract: inputs, result, and possible effects. Prefer returning a value to printing inside business logic. Local names belong to each call, but a default argument is evaluated when the function is defined.

A mutable default list can therefore survive across calls. Use None as the default and create a list per call. If the caller supplies a list, this exercise deliberately returns a copy; it does not mutate the caller.
