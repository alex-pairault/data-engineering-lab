Continuous integration runs defined checks for a source state. A workflow contains jobs and steps; jobs without dependencies may run independently. A release job that must wait for checks needs an explicit dependency such as needs.

Trace source identity through checks, build artifact and deployment. Green checks for A do not establish that an artifact from B was tested. Keep provenance explicit: commit, commands, results, artifact identity and deployed version. A platform may enforce some links; inspect the actual workflow rather than assuming them.

The public learning repository runs Node tests, executable Python exercises and static-build checks. Inspect its workflow and a run for the current commit. The hosted Sites publication is a separate workflow: a green source check alone does not prove which build is live.

Passing CI is evidence for its assertions and environment. It does not prove all user behaviour, production configuration or recovery works. After release, verify a representative operation and health signal, know the rollback boundary, and distinguish code rollback from data restoration.
