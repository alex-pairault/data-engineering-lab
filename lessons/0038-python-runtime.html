Trace the input, decision, and result. This diagram simplifies the mechanism; your local code tests its stated contract.

Python is the language; CPython is its most common implementation. A virtual environment selects an interpreter and isolated installed packages. It does not sandbox your program. Run python --version, then python -c "import sys; print(sys.executable)" and python -m pip --version.

The exercises target Python 3.12 or newer. Use the prepared Python 3.12 environment for the library exercises; newer syntax is introduced only in the migration lesson. Python 2 examples are historical: Python 2 is unsupported. A version is not a performance guarantee.
