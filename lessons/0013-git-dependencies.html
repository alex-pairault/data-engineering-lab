02 / EXPLORE

Follow the mechanism.

A Git merge combines divergent histories. Conflict markers identify text Git could not combine automatically. They do not identify the correct business behaviour. 

<<<<<<< HEAD
return 0 if amount < 10000 else amount // 20
=======
return 0 if amount < 5000 else amount // 10
>>>>>>> feature-rate

The base had threshold 5000 cents and rate 5%. Main raised the threshold to 10000; the feature raised the rate to 10%. The requirement is to keep both. Choosing either complete side loses one accepted change. Check 9999, 10000, and 20000 cents. Read the resulting diff, run behaviour checks, stage the resolution, inspect the staged diff, and commit.

Reproducibility also includes dependencies. A manifest, such as package.json, declares dependencies and allowed versions. A lockfile records the resolved dependency graph, including transitive dependencies. Review and commit the intended pair. Pinning direct dependencies alone does not necessarily pin everything they depend on.

For npm, npm ci expects a matching existing lockfile, removes an existing node_modules directory in that project, and installs the locked tree without updating the manifest or lock. It rejects a mismatch rather than silently choosing a new graph. A deliberate dependency change normally uses the chosen package-manager workflow to update and review the lock.

A lockfile helps reproduce dependencies, not an entire computer. Runtime/package-manager versions, install flags, native components, registry access, and platform still matter. Deleting a conflicted lockfile is not a general repair: first resolve the intended manifest, then regenerate or resolve and verify using the project's toolchain.
