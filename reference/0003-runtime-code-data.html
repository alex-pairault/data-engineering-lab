A running service

Process: running program instance; PID identifies the process.
Endpoint: address + port + protocol in a network context.
Connection → HTTP responder → route → application behaviour.

A process can listen on several ports or none. A controlled refusal has no HTTP status; a 404 means an HTTP responder handled the request, though it may be the wrong deployment. Compare endpoint, service identity, and logs.

Startup configuration captured by a process does not automatically change when a shell variable or file changes. Python does not load .env files on its own. Reconfigure or restart according to the actual runtime's behaviour.

Merge behaviour and reproduce dependencies

Resolve a conflict from accepted requirements. Removing markers, choosing a side, or staging a file does not establish correctness. Inspect the final and staged diffs; run behaviour checks.

Manifest
Declares dependency requirements, often including allowed version ranges.
Lockfile
Records the resolved graph, including transitive dependencies. Review and commit the intended manifest/lock pair.
npm ci
Requires an existing matching lockfile, removes existing node_modules in its project, installs the locked graph, and does not rewrite the manifest or lock. Runtime, flags and platform still matter.

Container lifecycle and state

Image
Packaged files and runtime configuration. Multiple containers can start from it. A tag may move; a digest identifies a snapshot.
Container writable layer
Runtime writes belonging to that container. Stop/start retains it; removal discards it.
Named volume
Storage mounted outside the writable layer, retained across container removal until the volume is removed. Persistence is not a backup.
Port publishing
127.0.0.1:18080:8000 maps host loopback 18080 to container 8000. The application still listens inside on 8000. EXPOSE alone does not publish a port.

CPU and memory limits constrain a container's budget. Measure actual output and resource use; extra workers can increase memory pressure. The teaching counter is single-process, not a production server.

Preaggregate each child per order → join one total from each.

State what one row represents before trusting a metric. SUM(DISTINCT amount) can remove legitimate equal amounts. A primary key protects row identity; a foreign key checks references and does not imply one-to-one cardinality. Add the business uniqueness rule explicitly when required. Enable SQLite foreign keys for each connection.
