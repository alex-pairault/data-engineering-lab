The everyday core

Questions to ask when reading Python
Area Working rule Common trap
Values Use is None for explicit absence; == for value equality. value or default replaces a valid zero.
Collections list: sequence; dict: key/value; set: membership; tuple: immutable outer sequence. A tuple may still contain a mutable list.
Functions Inputs, return value, exceptions, and effects form the contract. A mutable default can be shared across calls.
References Assignment binds a name; shallow copies reuse nested references. A new outer dict does not isolate its nested list.
Errors Catch specific failures where recovery is meaningful. Returning zero or [] can disguise a failure as success.
Iteration yield produces on demand; an iterator can be exhausted. sorted/list or an unbounded seen set can still retain the input.
Types Hints help readers/checkers; validate external boundaries. A dataclass annotation alone does not reject malformed input.
Resources Use context managers; explicitly close a partially consumed file generator. Early break alone does not close a retained generator.

Small syntax patterns to recognize

Use these as a lookup after recall. Choose a clear loop when it is easier to debug than a dense comprehension. 

# Iterate with an index; unpack a pair; format a readable string.
for index, (name, score) in enumerate([("Mina", 7)], start=1):
    print(f"{index}: {name} scored {score}")

# Transform or filter; sorting returns a new list.
squares = [n * n for n in range(5) if n % 2 == 0]
ranked = sorted([("Mina", 7), ("Owen", 9)], key=lambda pair: pair[1])

# zip(strict=True) rejects unequal lengths instead of silently truncating.
pairs = dict(zip(["a", "b"], [1, 2], strict=True))

# A keyword-only option makes the caller's intent explicit.
def label(name: str, *, uppercase: bool = False) -> str:
    return name.upper() if uppercase else name

label("Mina", uppercase=True)

Recognize indexing/slicing, unpacking, comprehensions, enumerate, zip, key functions, f-strings, keyword arguments, and *args/**kwargs. Do not add flexible variadic interfaces where an explicit signature is clearer. Control flow and function arguments · zip strictness

CPUexecution and caches

Compare equal-output implementations at two bounded sizes. Use fresh processes; time without tracing, then measure traced allocations separately. Elapsed time includes waiting; CPU time measures this process's CPU consumption. tracemalloc peak is not process RSS, and getsizeof is shallow.

CPython reference counting and cycle collection describe implementation behaviour. del removes a binding; other references, allocator reuse, and native memory can keep RAM resident. Streaming bounds current-row state, but accumulators and downstream materialization can still grow.

Useful standard library modules: pathlib, json, csv, collections, itertools, dataclasses, typing, decimal, datetime, zoneinfo, logging, argparse, contextlib, sqlite3, concurrent.futures, asyncio, time, tracemalloc, and tomllib. Learn how to locate their docs and choose a contract; memorizing every API is unnecessary.

Not every project needs every library. NumPy is installed transitively by the recorded pandas environment; the other extension libraries are optional and are not required by the timed exercises. Local mocks and test clients do not verify remote services, network timeouts, or production infrastructure.

Version awareness

Snapshot checked November 5, 2026: Python 3.15 is stable; 3.10 is end-of-life. Use the official status table on the day you choose an interpreter. The exercises use 3.12-compatible syntax and a recorded 3.12 package environment.

  • 3.10: pattern matching; X | Y unions.
  • 3.11: ExceptionGroup, TaskGroup, tomllib.
  • 3.12: type-parameter syntax and type statements.
  • 3.13: experimental optional free-threaded CPython.
  • 3.14: deferred annotation evaluation; supported optional free-threaded builds.
  • 3.15: UTF-8 mode default; explicit lazy imports.

Read Porting, Removed, and dependency-wheel compatibility, then run the actual checks under each supported interpreter. New syntax must parse before a runtime if can execute. A feature probe compiling a string is safer than importing a newer-syntax module on an older interpreter.

Pydantic v1 → v2: use model_validate / model_dump, and check changed validators, configuration, and coercion. A method rename alone is not a complete migration.
