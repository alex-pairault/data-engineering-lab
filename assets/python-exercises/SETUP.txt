FIELDNOTES PYTHON PRACTICE · 30 SESSIONS

All data is synthetic. This workspace executes real local Python, never browser
JavaScript pretending to be Python. Setup is separate from the 30-minute sessions.
The core language examples target Python 3.12+. The tested library environment
uses Python 3.12; exact resolved packages are in requirements.lock.txt.

Linux / macOS (replace python3.12 with your Python 3.12 executable):
  python3.12 -m venv .venv
  .venv/bin/python -m pip install -r requirements.lock.txt
  .venv/bin/python tools/check.py 01

Windows PowerShell (with Python 3.12 installed):
  py -3.12 -m venv .venv
  .venv\Scripts\python.exe -m pip install -r requirements.lock.txt
  .venv\Scripts\python.exe tools/check.py 01

You may activate the venv, then use the lesson's short `python` commands:
  Linux/macOS: source .venv/bin/activate
  PowerShell: .venv\Scripts\Activate.ps1
Or always use the explicit interpreter path above if activation is unavailable.

OPTIONAL uv alternative (if already installed):
  uv venv --python 3.12 .venv
  uv pip sync --python .venv/bin/python requirements.lock.txt
  .venv/bin/python tools/check.py 01

The memory probe measures prepared eager/stream implementations, not your
exercise function automatically. It bounds its two sizes to <=1,000,000 each and uses fresh local
processes. Traced Python allocation bytes are not process RSS. The process-pool
exercise uses spawn and small finite inputs; run tests from this folder, and do
not trigger a pool at module import. HTTPX tests inject in-process responses;
FastAPI TestClient tests local ASGI behaviour. No exercise sends remote HTTP
requests. Database tests use disposable in-memory SQLite. Package installation
is the only step that requires internet access.
